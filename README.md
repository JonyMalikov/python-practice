# Python Practice

Репозиторий с учебными задачами по Python, SQL и алгоритмам.

## Структура

- `01_basics/` — базовый Python
- `02_oop/` — ООП
- `03_data_structures/` — структуры данных
- `04_sql/` — SQL-запросы
- `05_leetcode/` — алгоритмические задачи

## Как запустить

```bash
uv run python <путь>/solution.py
```
